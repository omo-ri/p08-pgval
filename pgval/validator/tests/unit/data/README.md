# Данные юнит-тестов

- plan.json, inputs.json — самостоятельный маленький пример SST для проверки Oracle.
- expected.json — вручную рассчитанный ответ, не используется при выполнении эксперимента.
- corrupted.json — результат с пропуском ID 3 и повтором ID 1 для проверки обнаружения ошибок.

Эти файлы принадлежат юнит-тестам. Проверка сохранённого запуска Flink использует архив в `app/checks/sst-gen/results/20261103T155921`.
