# Прототип исполнителя

Локальная проверка управления внешним процессом. Python запускает JVM, ждёт ready и передаёт события по UTF‑8 JSONL. Java-цель удваивает значение и удерживает ответ e2 на стадии before_result. C0 разрешает продолжение. C1 отправляет SIGKILL конкретной JVM, ждёт код −9, запускает новую JVM и повторно подаёт e2. После второго барьера приложение получает разрешение продолжить. Для обоих прогонов ожидаются e1=4, e2=6, e3=10.

## Запуск

Из корня репозитория в Linux или WSL нужны Python 3.12, Java 11+ и JDK либо Docker с доступным daemon для сборки. При наличии Docker Desktop в WSL сборка также умеет вызвать docker.exe. Java-процесс запускается в самом Linux.

```bash
bash pgval/executor/demo/check.sh runs/executor-demo
```

Команда собирает demo/build/stub.jar, запускает C0, C1 и шесть отрицательных проверок. Для повтора задайте новый каталог либо опустите аргумент, чтобы скрипт выбрал имя. Полные результаты сохраняются в runs/. Зафиксированный короткий прогон доступен в [demo/results/kt1](demo/results/kt1/).

Можно выполнить сценарий отдельно после сборки.

```bash
python3 -m pgval.executor run \
  --scenario pgval/executor/demo/scenarios/local-restart.json \
  --out runs/restart-only
```

## Граница с командным планом v2

Сценарии демо описывают команду процесса, файлы входа и ручного эталона, а также таймауты. В журнале различаются сигнал приложения, отправка SIGKILL, подтверждённый выход и новая попытка. Записи отправки и подтверждения отказа связаны одним action_id из сценария, ID события и PID. Ручная сверка относится к Java-демо. Для SST ответ независимо вычисляет командный валидатор.

Общий запуск будет принимать [plan.json v2](../PLAN.md) через существующий pgval.plan. Первый сквозной сценарий использует один раздел Kafka и проверенный перезапуск TaskManager из [стенда](../app/README.md). Нужно выполнить publish и fault из плана, записать фактическое применение и снятие воздействия с action_id, собрать click.jsonl, output.jsonl и lateOutput.jsonl, подтвердить финализацию и передать файлы [валидатору](../validator/README.md). Затем команда подключит сигнал выбранной новой топологии и новый отказ.
